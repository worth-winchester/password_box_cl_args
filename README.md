# password_box_cl_args

Author: Worth Winchester

Description: Password_box_cl_args is a command line password manager.
The program takes command line arguments as input.
It utilizes the sqlite3 and cryptography Python libraries.
Passwords are stored in a sqlite3 database file (.db).
The database file is encrypted and decrypted with 128-bit AES using the user's master password.
The program can also generate pseudo-random passwords.
